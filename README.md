# Data-Science-Portfolio-Projects
​A curated portfolio of 5 end-to-end Data Science & Machine Learning projects covering Churn Prediction, Sales Forecasting, Demand Forecasting, Defect Detection, and Predictive Maintenance.

# Data Science & Machine Learning Portfolio Projects

This repository contains 5 machine learning projects covering classification, regression, and deep learning:

1. Customer Churn Prediction: Telecommunications churn classification using Logistic Regression and XGBoost.
2. Sales Forecasting Analysis: Retail store sales prediction using Linear Regression and Cross-Validation.
3. Bike Rental Demand Prediction: Hourly demand forecasting comparing Linear Regression and Keras Neural Networks.
4. SECOM Defect Detection: High-dimensional semiconductor defect detection using Random Forest, SMOTE, and custom threshold tuning.
5. Predictive Maintenance System: Industrial machine failure classification using Gradient Boosting and hyperparameter optimization.
